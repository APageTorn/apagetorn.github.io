THE USER MANUAL

Subject: How Spell complexity increases with Tier

Prerequisite: Read through Book 1 before opening these notes.

Spell Complexity

Spells complexity increases with tier. The following table is for cast spells. Enchanting follows a similar complexity increase.

Tier Number of Symbols Timing Hands
0 1 None 1
1 2-4 None 1
2 4-6 None 1
3 6 Timing between each symbol 1
4 6-12 Timing between each set of symbols, right and left hand together 2
5 12 Timing between each symbol, right and left hand independent 2
FIELD NOTE ON TIER 6 :
There are no known tier 6 spells.

Spell Architecture

There are four types of higher tier spells.

1. Combination Codes (Lowest Difficulty):
Combines two or more lower-tier spells. If all prerequisite lower-tier spells are already mastered, these are the easiest type to learn. Usually, only one primary prerequisite is a hard requirement. The more secondary prerequisites that remain unlearned the more difficult it is to learn.

2. Amplified / Stronger Versions (Moderate Difficulty):
As a direct tier-upgrade to an existing prerequisite, there can't be any unlearned prerequisite for this type of spell, but it is about twice as hard to learn new functionality as it is to learn a combination spell.

3. Amplified / Added Functionality (Elevated Difficulty):
As direct tier-upgrade to an existing prerequisite, there can't be any unlearned prerequisite for this type of spell, but in adding additional functionality it gains difficulty, since the is a cost for the additional functionality and for the combination.

4. Standalone / No-Prerequisite Codes (Highest Difficulty):
New spells requiring no antecedent knowledge are the most difficult to learn. They involve a deep learning of the functionality along with the combination cost.
